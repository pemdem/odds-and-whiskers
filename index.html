Tutorial

Getting started

Three steps, about five minutes. Want every detail and what to do if something goes wrong? Switch to Full guide.

Every step in detail, how to use the app, updates, and fixes for common problems.

  1. Download and unzip

    Click Download for Windows above. Right-click the zip → Extract All… → Extract.

  2. Double-click Install Odds and Whiskers

    If Windows says “Windows protected your PC”, click More info → Run anyway. Wait 2 to 3 minutes; it opens the app by itself.

  3. Follow the welcome

    You start in practice mode (fake money, real prices). The welcome connects your Kalshi account when you’re ready, and offers a tour.

  1. Download the package

    Click Download for Windows above to get OddsAndWhiskers-2.1.0-windows.zip (333 KB). Works on Windows 10 and 11. Nothing else to install first.

  2. Unzip it

    In your Downloads folder, right-click the zip → Extract All… → Extract. A folder called Odds and Whiskers opens. (Double-clicking inside the zip without extracting won’t work; the installer tells you if that happens.)

  3. Run the installer

    Double-click Install Odds and Whiskers. Windows may show “Windows protected your PC” because the app isn’t signed with a paid certificate: click More info → Run anyway. A window shows four steps:

    1 · it copies the app to your user folder (AppData\Local\Odds and Whiskers), so you can delete the download afterwards · 2 · it uses your Python 3.11–3.14 if you have one, otherwise it downloads its own private copy and checks its fingerprint · 3 · it installs the parts the app needs · 4 · it adds an icon to your Desktop and Start menu, then opens Odds & Whiskers.

  4. Practise first

    The app starts in practice mode: fake money on real Kalshi prices. Take the Quick tour (1 minute) or the Full tour (5 minutes) from the welcome or Help (?) → Show me around. Hover anything to see what it means.

  5. Connect your Kalshi account (real money only)

    On kalshi.com, open your account settings → API keys → Create key. Kalshi shows a Key ID and downloads a private key file. In the app’s welcome (or Settings → Kalshi account) paste the Key ID and choose the file. It’s stored only on your PC, encrypted and locked by Windows Credential Manager, and never shown again.

  6. Move money and go live (real money only)

    If your money is in another part of your Kalshi account, the app moves it to the crypto section. Then pick the most the bot may use and a risk level (start at Tiny) and type the confirmation phrase shown. Capitals and spaces don’t matter, and a ✓ appears when it matches. The app reopens in real-money mode. The confirmation lasts 30 days.

Using the app

Status

The chip at the top says Running, Watching, Paused, Offline or Needs attention. Click it for each coin’s “Why no bet?”.

Pause or stop

Pause stops new bets. Kill switch blocks them until you undo it. Closing the window doesn’t stop the bot; Help → Close, pause or turn off explains the difference.

Ask your sidekick

Click it and ask: “What happened while I was away?”, “Which coin is doing best?”, then “why?”. Answers use your own data and label every number.

Updates

The app checks this website twice an hour and shows Update available. Click Install: new bets pause, your data is backed up (history, settings, Litter Box, key vault), the update installs and every order is re-checked before betting resumes.

If something goes wrong

“This needs the whole folder”
You opened the installer inside the zip. Right-click the zip → Extract All…, then run it from the extracted folder.
The installer stopped with a message
Usually the internet dropped. Run Install Odds and Whiskers again; it picks up where it left off and never touches your settings, key or data.
The confirmation phrase “doesn’t match”
Type the words and the code exactly as shown (capitals, spaces and dashes don’t matter). If you change the amount, cap or risk level afterwards, the phrase changes: the app asks for the new one.
The window looks empty
Close it and open Odds & Whiskers again from its icon. The bot keeps running in the background either way.
Something else
Help (?) → Export diagnostics makes a small file without keys, balances or amounts. Send it to whoever shared the app with you.
Real money is your call. This strategy has not been shown to be profitable. A win pays a few cents per contract and a loss costs the whole price. Start small, and use practice mode and the Litter Box first.
Your setup stays yours

One app, separate accounts

On your computer only

Your Kalshi key, limits, settings, layouts, trade history and Litter Box results never leave your computer and are never replaced by an update.

Learns from you

Strategy recommendations come from your own results. Nobody's account or bets are shared — only the app itself is.

Same updates everywhere

Windows and Mac copies check this website for new versions. Every update is signed, so the app only installs updates from the Odds & Whiskers publisher.

Getting updates

Nothing to set up. The app checks this website for new versions twice an hour. When one is out, it shows Update available. Click Install and it does this by itself:

New bets pause→Waiting bids are cancelled→ Your history and settings are backed up→The update installs→Every order is re-checked with Kalshi→Betting resumes

Bets that already filled are never touched. After each new version, a What's new popup shows once, and Settings → Updates keeps the full history.
